# Короткая ипотечная анкета · Циан

Промо-ролик о короткой ипотечной анкете, собранный скиллом product-motion.

- Статус: готово.
- Формат: 16:9, 1600×900, H.264 MP4, 15 секунд, без звука.
- Источник сцен: реальные состояния существующего прототипа анкеты — старт, контакты, планы покупки, финансы, время звонка и экран успеха.
- В кадрах использованы демонстрационные ответы: срок покупки, доход и ежемесячный платёж по кредиту.
- Бренд-профиль: `brand/` (снимок на момент создания: ../brand).

## Результат

Готовый файл: `out/mortgage-short-form-promo.mp4`.

## Рендер

HTML-рендер через Chromium был подготовлен, но запуск браузера в текущем sandbox блокируется. Поэтому для финальной сборки применён локальный fallback: те же реальные экранные состояния были собраны как векторные кадры, растеризованы и склеены через ffmpeg. Это не меняет содержание или визуальный сценарий ролика.

## Пересборка

Команды — в разделе «Процесс» скилла product-motion. Превью в браузере: `video.html?preview=1`
(через локальный сервер из этой папки: `python3 -m http.server`). Временные файлы — в `build/`, результаты — в `out/`.
